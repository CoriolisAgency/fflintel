ATF's public listing of federal firearms licensees tells you how many licenses were on a named month's file, and of what type. It can't tell you how many of those licensees sell only online. It can't tell you how many work from a home. Those aren't fields on the official file. A count of "home-based FFLs" or "online-only FFLs" on a third-party map is that author's label, not ATF's. We will not invent one.

## What the official file contains

The listing is a license file. Each row is a license.

The July 2026 complete list we counted for [how many FFLs are there](/how-many-ffls/) has these columns: license region, district and county codes, license type, an expiration code, a sequence number, business name, premises street, city, state and ZIP, mailing street, city, state and ZIP, and a voice phone number. One more column has a blank header.

That's the whole file. There's no column for how a licensee sells, and none for what kind of building the premises is.

For the citable count, go to [how many FFLs are there](/how-many-ffls/). It has 77,485 licensees, counted from ATF's July 2026 file, as of ATF's July 2026 listing, excludes Type 03.

## What the file does not contain

- No "online only" flag.
- No "home based" flag.
- No "sold a gun this month" flag.

Some sites run licensee addresses through a geocoder and call some of them residential. That's their classification. It isn't an ATF category, and this desk won't treat it as one. We don't reprint those shares.

A Type 01 dealer license at an address that looks like a house still tells you nothing about how that dealer sells. Some sell at gun shows. Some sell by appointment. Some sell online. The file doesn't say which.

## Why people ask anyway

People ask how many home-based FFLs there are for a fair reason. The industry clearly includes licensees without a classic storefront. Anyone who's been around dealers knows that.

Knowing a group exists isn't the same as having an official count of it. No public official count exists. A number built from address guesses is a guess with a decimal point.

## If you don't have a storefront

A dealer without a counter still has to source inventory through channels the law allows, and still has to be found by shoppers, which for a dealer without a storefront usually means a website.

## Short answers

**How many home-based FFLs are there?** There's no official count. ATF's public listing has no field that flags a licensee as home-based. We won't build one from address guesses. The official figures are license counts by type and state, from a named month's ATF file. See [how many FFLs are there](/how-many-ffls/).

**How many online-only FFLs are there?** There's no official count. The same file has no field that flags a licensee as online-only. A Type 01 license at a given address isn't a statement about how that licensee sells.

**What can the official file tell you?** For a named month, how many licenses were listed, of what type, and the information ATF publishes for each one. It can't tell you who made a sale that month, who sells only online, or who works from a home.

## How we update

If ATF ever adds a field that answers this question, this page changes. Until then the answer stays "the file can't tell you." The countable series live on [how many FFLs are there](/how-many-ffls/). If that page moves to a newer ATF month, this one gets checked too. That's [how we cite](/methodology/).
